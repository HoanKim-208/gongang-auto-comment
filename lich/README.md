# Lịch comment — mỗi bài 1 file

Thêm comment cho bài ảnh/album: upload 1 file `<ten-bai>.json` vào thư mục này, không cần sửa `lich.json`.

```json
{
  "ten": "B3 Gõ khuya sợ ồn (ảnh đơn)",
  "tu_khoa": "cụm chữ độc nhất trong caption",
  "thoi_gian": "2026-09-25T22:05:00",
  "noi_dung": "Nội dung comment, xuống dòng viết \n",
  "trang_thai": "cho"
}
```

Reel đăng qua `cho-dang/` thì máy tự tạo file `reel-<slug>.json` ở đây. `lich.json` cũ vẫn được đọc.
